# 樗蒲宫棋

纯 HTML / CSS / JavaScript 实现的樗蒲五木 + 32×32 迷宫宫棋。支持人机与双人对战。

## 在线游玩

部署完成后可在此访问：

**https://chongzzhang.github.io/chupu_qi/**

## 本地运行

```bash
# 在项目目录启动静态服务器
python -m http.server 8080
```

浏览器打开 `http://127.0.0.1:8080`

## 操作

- **投五木**：点击底部「投五木」
- **行走**：方向键或点击相邻通路格
- **王采技能**：贵采可暂存，之后任意回合使用
- **地图**：滚轮缩放，拖拽平移

## 目录

- `index.html` — 入口
- `css/` — 样式
- `js/` — 游戏逻辑（迷宫、五木、AI、渲染等）
- `scripts/` — 逻辑自测脚本
